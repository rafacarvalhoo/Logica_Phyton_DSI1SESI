BOX MODEL

Content (conteudo)

Define a largura da caixa (salvo elemntos de bloco)

Padding (preenchimento)

Separa o conteudo das bordas da caixa. É a margem interna

Border (borda)

Define bordas para a caixa

Margin (margem)

Define a distância entre a caixa e os outros elementos

Width (largura)

A largura total da caixa, por padrão é o somatório de conteúdo + padding (left/right) + border (left/right)

Height (altura)

A altura total da caixa, por padrão é o somatório de conteúdo + padding (top/bottom) + border (top/bottom)
